# The Objective  

### Utilize PyQt6 GUI creation along with the 4 Pillars of OOP to create a program that targets a real-issue.  

# The Problem  
Academic studies have proven that stressful environments alongside a lack of available studying environments negatively affect student learning.  
As such, ease of use and access for students is imperative for providing equal and accessible education to all (aligned with SDG 4).  

# The Proposed Solution  
A library heatmap program where (1) Students may update seat status (if occupied or free) and reserve for their own seats ahead of time for maximum library space optimization,  
(2) Librarians are able to override seat status regardless of who set them, as well as track seat reservation logs through records, and  
(3) Admins who have a access to the Student Login records, complete with date and timestamp.  
The idea is to lessen stress in searching for available seats in the library, as well as being able to use the maximum capacity of the library as much as possible (especially during exam week).
